# Meu primeiro projeto com Claude Code

Explorando o fluxo de contribuição com Pull Requests usando o Claude Code.

## Sobre

Este repositório foi criado para praticar o fluxo completo de PR:
1. Criar uma branch
2. Fazer uma mudança
3. Abrir um Pull Request

## Como contribuir

1. Faça um fork do repositório
2. Crie uma branch: `git checkout -b minha-melhoria`
3. Faça suas alterações e commit: `git commit -m "feat: minha melhoria"`
4. Abra um Pull Request
